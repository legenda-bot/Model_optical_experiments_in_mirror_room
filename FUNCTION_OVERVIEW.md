# Обзор кода `modelation_of_mirrors`

Этот файл — «карта» проекта: где что находится и как устроены ключевые алгоритмы.

## Общая идея

Приложение рисует комнату (многоугольник), стены могут быть:
- **Flat** — плоское зеркало (отрезок).
- **Spherical** — сферическое зеркало, отрисованное как дуга окружности, проходящая через концы стены.

Луч света строится как ломаная из отражений от стен.

## `MirrorRoom` (`mirrorroom.cpp/.h`)

Отвечает за:
- построение комнаты (ручное кликами или правильный многоугольник),
- отрисовку стен и луча,
- выбор стартовой точки и угла,
- управление анимацией луча (пошаговая подсветка сегментов),
- зум/панорамирование.

Ключевые методы:
- `completeRoom()` — создаёт `Wall` из вершин и вычисляет центр комнаты (centroid), который передаётся в стены через `Wall::setRoomCenter(...)`. Центр нужен для ориентации «внутрь/наружу».
- `findWallAtPoint(...)` — выбор стены по клику (использует `Wall::containsPoint`).
- `drawWalls(...)`, `drawRay(...)` — отрисовка.

## `Wall` (`wall.cpp/.h`)

Хранит геометрию конкретной стены:
- `QLineF m_line` — хорда (концы стены).
- `MirrorType`, `SphericalType` (Concave/Convex), `m_radius`.
- `roomCenter` — центр комнаты для определения «внутренней» стороны.

Ключевые методы:
- `draw(QPainter&)` — рисует хорду (всегда), и если `Spherical` — дугу окружности, которая проходит через концы хорды.
- `distanceToPoint(...)` и `getClosestPoint(...)` — используются для кликов по стенам и для «прилипания» стартовой точки. Для сферической стены учитывается не только хорда, но и дуга.
- `setRadius(...)` — «защитный» сеттер: не даёт записать некорректные значения (NaN/inf, слишком маленький радиус и т.д.).

### Геометрия дуги сферической стены (важно)

Дуга определяется:
- концами хорды `p1`, `p2` (это концы стены),
- радиусом кривизны `R` (задаётся пользователем),
- выбором стороны «внутрь/наружу» относительно `roomCenter`:
  - **Concave** (вогнутая) — дуга смотрит внутрь комнаты,
  - **Convex** (выпуклая) — дуга смотрит наружу.

Центр окружности лежит на перпендикулярном биссектрисе хорды. Для малой дуги (<= 180°) важен факт:
**малая дуга находится на стороне, противоположной центру окружности**.
Из‑за этого при выборе стороны дуги центр берётся на противоположной стороне.

## `LightRay` (`lightray.cpp/.h`)

Строит траекторию луча:
- `calculatePath()` — основной цикл отражений.
- `findNextWall(...)` — ищет ближайшую стену по направлению луча:
  - для `Flat` — пересечение луча с отрезком,
  - для `Spherical` — пересечение луча с окружностью и фильтрация «точка лежит на дуге».
  Важно: у окружности всегда 2 пересечения — выбирается ближайшее положительное, которое реально лежит на дуге.
- `calculateReflection(...)` — отражает направление луча:
  - `Flat` — отражение относительно нормали отрезка,
  - `Spherical` — отражение относительно нормали окружности в точке касания.

## `WallDialog` (`walldialog.cpp/.h`)

Диалог настройки выбранной стены:
- выбор типа зеркала (Flat/Spherical),
- выбор типа сферического зеркала (Concave/Convex),
- выбор радиуса кривизны `R`.

Валидация:
- радиус должен быть конечным числом,
- радиус должен позволять окружности проходить через концы хорды: `R >= длина_стены / 2` (с небольшим допуском),
- слишком большие значения ограничиваются.

Также во время эксперимента редактирование стен блокируется.

## `MainWindow` (`mainwindow.cpp/.h`)

UI панель справа:
- режим создания комнаты,
- настройки эксперимента (угол, скорость),
- запуск/очистка.

Сигналы:
- `wallSelected` открывает `WallDialog`,
- `simulationStateChanged` блокирует элементы UI и редактирование стен на время работы эксперимента.
