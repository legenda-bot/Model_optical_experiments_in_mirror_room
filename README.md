# Модель оптических экспериментов в зеркальной комнате

Авторы: **Касаткин Александр**, **Фатыхов Арон** (11 И)

Проект — Qt (Widgets) приложение, которое моделирует путь светового луча в «зеркальной комнате» (многоугольник со стенами‑зеркалами). Пользователь строит комнату, задаёт тип стен и параметры луча, после чего программа рассчитывает траекторию отражений и анимирует её отрисовку.

## Возможности

- Создание комнаты:
  - вручную кликами (до **9** точек),
  - правильный многоугольник (4–9 стен).
- Типы стен:
  - `Flat` — плоское зеркало,
  - `Spherical` — сферическое (дуга окружности), тип `Concave/Convex`, радиус.
- Выбор стартовой точки на стене/дуге и угла луча.
- Анимация траектории с настройкой скорости.
- Сохранение/загрузка эксперимента.

## Структура

- UI (Qt): `mainwindow.*`, `mirrorroom.*`, `wall.*`
- Траектория: `lightray.*` (делегирует расчёт в backend)
- Backend (логика без Qt): `backend/BackendWall.*`, `backend/BackendPolygon.*` (`BackendMirrorRoom`), `backend/ExperimentDatabase.*`
- Геометрические примитивы: `Point/Vector/Line/Segment/Ray/Circle/Arc/Intersections`

Диаграмма классов: `class_diagram.puml`

## Сборка (qmake)

Проект — qmake (`modelation_of_mirrors.pro`).

Пример для Windows + MSYS2 MinGW64:

```powershell
cd modelation_of_mirrors
qmake6.exe -o Makefile modelation_of_mirrors.pro
mingw32-make.exe debug
```
